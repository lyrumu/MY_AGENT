# macOS 安全清理

仅服务于明确的系统清理、释放空间或可清理文件盘点需求。故障诊断（如清空废纸篓卡住、Finder 无响应、进程异常、磁盘错误）不属于本技能；不能因问题涉及废纸篓或缓存而转入清理盘点或审批流程。诊断后只有用户明确提出清理需求，才使用本技能处理该部分。

适用于不同 macOS 设备。每次从实际系统状态出发，不依赖某台机器的用户名、应用版本、目录清单或历史批准；非 macOS 不套用本技能命令。

## 边界

- 已明确要清理但未指定路径时，先只读盘点，等用户选当次编号或精确路径。默认保留源码、个人文件、账号、Agent 持久会话/状态、OpenCode 数据及项目 `.opencode`，不得从父目录间接清理。
- Cache/tmp/重复/年久/体积大均不是删除依据；不整包清空用户缓存、应用支持目录、容器、Agent 根目录或系统临时树。
- 使用现有工具，不安装依赖、不改系统或 shell、不运行 prune/VACUUM、不启动停止中的服务。命令加中文用途注释，临时诊断进程用后关闭。默认离线；需要联网时遵循当前环境的代理配置，不假定存在某个代理函数。权限被拒按工具规则申请，仍被拒即停止，不换手段绕过。

## 盘点与清单

读[动态排查](references/discovery.md)，按实际大项下钻，不能只扫常见 App 缓存。记录目标卷空间与目录实占，避免父子目录重复计量，注明 APFS 共享/稀疏块和权限限制。
聊天按日期/编号列出绝对路径、实测大小、用途证据、清理影响和退出要求，区分明确残留、可重建、需判断及保留项。优先高收益、低风险目标；可批准范围不得用通配符或宽泛父目录代替。**默认不生成报告文档**。

## 获批后的清理

1. 重新核验本批精确目标的真实路径、类型、所有者/ACL/flags、大小、mtime、链接与边界；排除重叠、受保护数据及新出现的个人文件。核查进程/打开文件，不能强退应用；无法排除占用或用途不明就跳过。
2. 操作前在当前任务的可写临时目录保存逐文件原路径、类型、大小、mtime，以及批准范围、源/落点映射和执行状态；用 JSONL/NUL 安全处理文件名。不为此次任务扫描或修改其他批次。
3. 默认使用现有原生工具可恢复地移入废纸篓；永久删除须对本批精确目标另获明确授权，不清空整个废纸篓。逐项核对工具输出、源路径与落点，不能只信退出码；失败或状态不明即停，不换命令绕过权限。
4. 核对已清/跳过/失败及相邻保留项，比较卷空间和原目录实占。明确同盘废纸篓不释放相应空间，后台活动/APFS 会影响差值；落点不可读时披露核验证据与限制。结果直接聊天交付，核验完成后清除本次临时审计、报告和辅助文件；状态未明或恢复依赖映射时仅保留必要记录并告知，解决后清除。用户要求保留的文档或跟踪基线除外。
