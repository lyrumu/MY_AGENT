# 内容与读者复核

先确定本篇读者想获得什么，再选择检查重点。以下是判断角度，不是固定目录或必须出现的章节。

| 内容类型 | 优先检查 |
| --- | --- |
| 教程、操作指南 | 前提是否必要且明确，关键动作是否可执行，读者是否知道成功的样子；按需要补常见阻碍和后续使用。 |
| 产品、新闻、知识解读 | 是否回答与读者有什么关系，事实与观点是否区分，证据能否支持结论；比较是否公平且条件一致。 |
| 观点、评论、经验 | 主张是否清楚，例子是否支撑判断，有无过度概括；个人经验的适用范围是否交代。 |
| 故事、随笔、人物 | 开头能否进入情境，细节是否有效，叙事与情绪是否连贯；不要强插操作步骤或总结口号。 |

复核时直接指出段落和问题，并改到稿件中：

- **缺什么**：读者会在哪里误解、卡住，或无法判断结论？补上解决这一问题所需的信息。
- **删什么**：删掉这句话，读者的理解、判断或操作会损失什么？没有损失就删除或合并；关键条件即使低频也不能一概删除。提供的资料不必全部纳入正文，不为补齐资料而扩展读者没有提出的需求。
- **看什么**：只扫标题和强调部分能否把握重点？每张图是否在相关段落附近、手机上可读？图片是否比文字更适合解释这一点？
- **证据是什么**：变化中的事实是否有当前依据？实际体验、官方示例、推断与生成示意是否标明身份？

评审结论要落到稿件或预览中的具体位置；不输出没有依据的“可读性 95 分”或“用户一定喜欢”。
